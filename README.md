# Service4All

A responsive business website created as part of the Faran Digital Academy Week 2 Web Engineering Task.

## Project Overview

Service4All is a modern digital solutions website designed to help businesses grow through web design, UI/UX design, mobile optimization, and SEO optimization.

## Technologies Used

- HTML5
- Tailwind CSS
- Responsive Web Design

## Features

- Responsive navigation
- Hero section
- About section
- Services section
- Testimonials
- Responsive footer
- Mobile and desktop layouts

## Design

The website is based on the Week 1 Figma design provided for the Faran Digital Academy task.
